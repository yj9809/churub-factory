# 초반 자동화 중심 밸런스 초안

> 이후 논의를 반영한 최신 수치·가격·해금 조건은 [통합 밸런스 표](BALANCE_TABLE.md)를 따른다. 이 문서는 초기 분석 근거와 이전 초안을 보관한다.

2026-09-09. 현재 작업 트리의 코드·프리팹을 읽어 만든 설계안이다. 게임에 적용하지 않았다. 실제 플레이 시뮬레이션이나 실기기 측정 결과가 아니다.

## 1. 계산 조건과 시간 해석

- 신규 시작, 광고 없음, 원재료 손실 없음. 원재료→가공품은 1:1, 가공품 5개→박스 1개, 트럭 5박스 적재 시 정산.
- 사용자가 제시한 원재료 운반 3초, 가공품 운반 1초, 박스 운반 2초를 기본 플레이어의 짐을 실은 편도 시간으로 가정한다. 원재료 도착지는 코드상 컨베이어 투입부로 해석했다.
- 기본 플레이어 빈손 속도 5, 적재 속도 2.5이므로 같은 경로 복귀 시간은 편도의 절반으로 가정한다. 왕복은 각각 4.5 / 1.5 / 3초다. 사용자의 시간이 왕복을 뜻했다면 아래 운반 소요는 2/3로 줄어든다.
- 기본 직원 속도는 빈손 3, 적재 1.5다. 같은 경로라면 플레이어보다 5/3배 오래 걸린다. 직원 원재료 왕복은 7.5초다.
- 생성 주기 3초, 원재료 재고 상한 10. 컨베이어는 3초 설정과 2.5초 프리팹 오버라이드가 공존한다. 초기 계산은 원재료 한 곳의 20개/분을 기준으로 한다. 추가 기계가 독립 생산라인인지, 병렬 투입과 이동 경로가 실제로 어느 정도 효율을 내는지는 실측 대상이다.
- 포장은 코드상 가공품당 0.3초, 박스 배출 0.3초: 박스당 최소 1.8초. 물리 충돌·FixedUpdate·다른 작업장 사이 이동·트럭 복귀·광고·고장은 별도다.
- 적재 이동 트윈 0.2초는 프레임마다 시작할 수 있으므로 물건 수×0.2초를 일괄 직렬 대기시간으로 더하지 않는다.

## 2. 현재 상태의 부담

첫 직원 전 컨베이어 5,000 + 사무실 2,500 + 직원 5,000 = 12,500골드. 초기 100과 고용 전 가이드 보상 4,100을 제외하면 판매 필요액 8,300. 트럭당 250이므로 34회, 170박스, 원재료 850개가 필요하다.

트럭 한 회(25개 원재료, 5박스)를 개별 묶음으로 처리하는 작업량:

| 작업 | 횟수 | 시간 |
|---|---:|---:|
| 원재료 운반, 3개 적재 | 9왕복 | 40.5초 |
| 가공품 운반, 3개 적재 | 9왕복 | 13.5초 |
| 박스 운반, 3개 적재 | 2왕복 | 6초 |
| 5박스 포장 | 5회 | 9초 이상 |
| 플레이어 작업량 합계 | | 69초 이상 |
| 원재료 25개 생성 | | 75초 |

생산과 작업은 겹친다. 따라서 75+69=144초를 실제 주기로 단정하면 안 된다. max(75,69)=75초는 이상적인 자원 하한이며, 144초는 두 일을 전혀 겹치지 않는 단순 비교값일 뿐 실제 상한도 아니다. 재고 제한·배치·작업 순서로 하한을 달성하지 못할 수 있다.

34회는 생산 하한 42.5분, 반복 묶음 기준 플레이어 작업량 39.1분이다. 두 시간을 더한 81.6분은 비중첩 참고값이며 플레이 시간 예측이 아니다. 이전 최소 운반 625편도 계산은 전체 물량을 최대로 묶은 수치이고, 이 문서의 34×20=680왕복 작업량에는 매 트럭마다 나머지 짐을 비우고 복귀하는 가정이 있어 직접 비교하면 안 된다.

원재료 전담 직원이 생기면 플레이어 작업량은 69→28.5초/트럭, 약 59% 감소한다. 생산 상한은 그대로 4박스/분이다. 첫 직원의 가치는 판매량의 무조건 증가보다 생산 중단 감소와 수동 노동 감소다.

직원이 매번 3개를 채워 왕복한다면 운반 능력은 3/7.5×60=24개/분으로 한 생산처 20개/분을 감당한다. 그러나 현재 AI는 가득 채우기 전에 목적지를 바꿀 수 있고, 원재료와 가공품을 공동으로 선택한다. 전담 역할과 적재 완료 규칙을 구현·검증해야 이 가정이 성립한다. 이동 시간이 두 방향 동일하다면 직원 왕복은 10초, 18개/분으로 부족하다.

## 3. 영구 업그레이드 전체 표

아래 비용은 각 단계에서 내는 금액이며 누적 비용이 아니다. 일반 업그레이드는 5단계, 직원은 무료 포함 총 3명 유지.

| 항목 | 현재 단계별 비용 | 제안 단계별 비용 | 제안 효과 |
|---|---|---|---|
| 플레이어 이동 속도 | 500 / 1,000 / 3,000 / 5,000 / 10,000 | 100 / 250 / 500 / 900 / 1,500 | 기본 대비 1.1 / 1.2 / 1.3 / 1.4 / 1.5배 유지 |
| 플레이어 적재량 | 500 / 1,000 / 2,000 / 4,000 / 8,000 | 150 / 300 / 600 / 1,000 / 1,600 | 3→4→5→6→7→8개 유지 |
| 박스 판매가 | 5,000 / 7,000 / 10,000 / 20,000 / 30,000 | 300 / 600 / 1,000 / 1,600 / 2,400 | 50→65→80→95→110→125골드 |
| 직원 이동 속도 | 500 / 1,000 / 3,000 / 5,000 / 10,000 | 100 / 200 / 400 / 700 / 1,100 | 기본 대비 1.1 / 1.2 / 1.3 / 1.4 / 1.5배 유지 |
| 직원 적재량 | 500 / 1,000 / 2,000 / 4,000 / 8,000 | 150 / 300 / 600 / 1,000 / 1,600 | 3→4→5→6→7→8개 유지 |
| 직원 고용 | 5,000 / 10,000 / 20,000 | 무료 / 1,200 / 3,000 | 원재료 전담 / 가공품 전담 / 포장 전담 |

현재 판매가 효과는 50→60→70→80→90→100이다. 제안에서는 각 단계에 15골드를 추가한다.

### 가격 선정 이유

- 적재 3→4는 25개 운반을 9→7회, 4→5는 7→5회로 줄인다. 5박스도 한 번에 옮길 수 있어 두 번째 적재 업그레이드가 명확한 목표다. 적재 5→6은 25개 배치 기준 횟수가 그대로 5회라 효과가 작다. 후반 적재 단계는 여러 생산처를 운영할 때 선택하도록 하고 강제 구매시키지 않는다.
- 원재료 직원 고용 뒤 플레이어의 모델 작업량은 적재 3/4/5에서 각각 28.5 / 25.5 / 19.5초/트럭이다. 적재 5까지 총 450골드로 작업량 약 32%를 줄일 수 있다.
- 속도 +10%는 이동 시간을 약 9.1% 줄일 뿐 생산 주기를 줄이지 않는다. 적재량보다 저렴하게 두고 편의 선택으로 제공한다. 기본 수치 기준 최종 플레이어 속도 7.5/3.75, 직원 4.5/2.25다. +10%가 단계마다 복리로 붙는 구조가 아니다.
- 직원 속도와 적재량은 운반 직원들이 공유한다. 포장 직원은 이동하지 않으므로 포장 속도 향상 효과로 안내하지 않는다.
- 현재 첫 판매가 업그레이드는 5,000/10=500박스가 있어야 비용을 회수한다. 한 생산처 이상적 4박스/분에서도 125분이다. 제안 첫 단계는 300/15=20박스, 이상적 5분, 70% 가동률이면 약 7.1분이다.
- 제안 판매가 각 단계의 한계 투자금 회수는 20 / 40 / 66.7 / 106.7 / 160박스. 한 생산처에서는 5 / 10 / 16.7 / 26.7 / 40분, 세 생산처가 실제로 3배 처리량을 낼 경우 1.7 / 3.3 / 5.6 / 8.9 / 13.3분이다. 후반 단계는 확장 이후를 전제로 한다. 구매까지 모으는 시간과 회수 시간은 서로 다르다.
- 두 번째 직원은 가공품 운반 부담, 세 번째 직원은 포장 체류를 제거한다. 포장 직원이 생겨도 박스 납품은 플레이어에게 남는다. 현재 직원 1·2는 역할이 구분되지 않으므로 이 표는 역할 분리 변경을 전제로 한다.

## 4. 시설 해금과 부수입

| 시설 | 현재 비용 | 제안 비용 | 배치와 이유 |
|---|---:|---:|---|
| 사무실 | 2,500 | 300 | 무료 직원 뒤 첫 업그레이드 허브. 직원 지급의 선행조건 제거 |
| 추가 원재료 컨테이너 1 | 1,000 | 600 | 추가 컨베이어와 한 쌍으로 안내 |
| 추가 컨베이어 1 | 5,000 | 900 | 위 컨테이너와 총 1,500. 한쪽만 사도 완성으로 오해하지 않게 표시 |
| 추가 원재료 컨테이너 2 | 5,000 | 1,800 | 중반 확장 선택 |
| 추가 컨베이어 2 | 10,000 | 2,700 | 위 컨테이너와 총 4,500 |
| 노점 | 10,000 | 1,200 | 초당 5→2골드로 조정. 회수 약 10분 |
| 상점 업그레이드 | 20,000 | 2,400 | 초당 10→4골드로 조정. 노점 대비 증가분 2골드/초, 회수 약 20분 |

현재 노점은 제품을 소비하지 않고 300골드/분, 상점은 600골드/분을 온라인에서 누적한다. 초기 수동 생산의 이상적 200골드/분보다 높다. 해금 가격만 낮추면 제품을 만드는 것보다 노점 대기가 유리해질 수 있어 수익도 함께 낮춘다. 제안 노점 120골드/분, 상점 240골드/분. 노점은 두 번째 생산라인 완성 이후, 상점은 세 번째 생산라인 이후에 선택 가능하게 한다. 수령 전 누적금과 소지금은 구분한다. 오프라인 수익을 의미하지 않는다.

직원 한 명이 세 원재료 생산처의 60개/분을 처리할 수 있다고 가정하지 않는다. 기본 원재료 직원은 이상적 24개/분, 적재 5는 40개/분, 적재 8과 속도 1.5배는 96개/분이지만 이는 동일한 짧은 경로와 완전 적재 가정이다. 새 컨테이너의 거리가 길면 부족해진다. 따라서 라인 수를 곱한 수익은 조건부 상한이다.

## 5. 튜토리얼 보상도 함께 수정

현재 0~6단계 보상 합계 2,100과 이후 각 1,000을 그대로 두고 가격만 낮추면 연쇄 구매가 발생한다.

제안: 초기 자금 100 유지. 0~6단계 보상은 25 / 25 / 50 / 50 / 50 / 100 / 100 = 400골드. 첫 트럭 250까지 합계 750. 첫 납품 완료 보상에 무료 원재료 직원 1명을 추가한다. 이후 건설·고용 단계의 1,000골드 보상은 없애고 안내 및 완료 표시만 남긴다. 단계 번호·하드코딩 안내문도 새 순서에 맞춘다.

첫 납품 후 예시 선택: 사무실 300 + 적재 1단계 150 + 판매가 1단계 300 = 750. 잔액 0. 그 다음 65골드×5박스=325골드/트럭, 4회 판매로 1,300을 모아 두 번째 직원을 고용하고 100이 남는다.

이는 특정 추천 구매 경로다. 모든 업그레이드를 사야 진행되게 만들지 않는다. 두 번째 직원과 생산라인 확장을 병렬 목표로 제시한다. 무료 직원은 총원에 포함하되 고용 가격 배수 계산을 타지 않는 별도 1회 지급으로 처리한다. 저장 후 재접속에도 중복 지급되지 않아야 한다.

## 6. 시간·수입 민감도

한 생산처 수입 공식: 4박스/분 × 판매가 × 실제 가동률. 가동률은 생산 중단·운반 병목 등을 합친 비교 변수이며 측정된 값이 아니다.

| 상태 | 100% 가동 | 85% 가동 | 70% 가동 |
|---|---:|---:|---:|
| 판매가 50 | 200/분 | 170/분 | 140/분 |
| 판매가 65 | 260/분 | 221/분 | 182/분 |
| 판매가 125 | 500/분 | 425/분 | 350/분 |

잔액 0, 판매가 65에서 두 번째 직원 1,200은 4트럭=1,300 정산이 필요: 100/85/70% 가동률에서 5 / 5.9 / 7.1분의 생산 기준 시간이다. 트럭 정산 대기와 첫 파이프라인 충전은 추가된다. 원재료 첫 25개 생산 하한은 75초. 무료 직원 지급 목표는 첫 시작 후 2~4분으로 잡되 이는 QA 목표이며 달성 보장이 아니다.

이동 시간을 왕복으로 해석하면 트럭당 수동 작업량은 49초, 원재료 직원 이후 22초다. 기본 해석 69→28.5와 절대값은 달라도 초반 자동화로 작업 부담을 줄인다는 판단은 유지된다.

## 7. 보조 시스템

| 항목 | 현재 | 제안 |
|---|---|---|
| 원재료 생성 | 3초/개 | 우선 유지 |
| 원재료 재고 | 10개, 30초분 | 20개, 60초분. 순간 작업 공백 흡수; 지속 처리량 증가는 아님 |
| 포장·트럭 | 5개/박스, 5박스/정산 | 유지해 변화 원인 분리 |
| 고장 | 시작/수리 뒤 300초 보호 후, 재료가 있는 배출 검사에서 3% | 첫 두 직원과 두 번째 라인 확보 전에는 비활성화, 이후 기존값으로 실측 |

| 광고 적재 | 플레이어 +3개, 30초 | +3개, 120초 |
| 광고 판매가 | 기본 버프 0에서 +1.5, 최종 2.5배, 30초 | 최종 1.5배, 120초 |

광고는 필수 수입에 포함하지 않는다. 현재 광고 완료 처리에는 버튼 비활성 여부로 버프 종류를 결정하는 동작이 있어, 이미 켜진 버프와 다른 버프가 섞이지 않도록 별도 확인이 필요하다. 이 제안의 배율은 구현 전 값이다.

## 8. 적용 전 확인 및 검증

1. 첫 무료 직원 지급·재로그인·기존 직원 보유 세이브 정책을 정의한다. 현 세이브는 가격과 능력치도 저장하므로 기본값만 바꿔서는 기존 유저에게 새 표가 적용되지 않는다. 자동 초기화는 하지 않는다.
2. 가이드의 트럭 5개 체크와 Truck.Update의 즉시 정산·스택 초기화가 같은 프레임에 경쟁할 여지가 있다. 판매 완료 이벤트 기반으로 단계 완료와 보상을 검증한다. 현재 모델은 가이드 보상이 정상 지급된다는 조건이다.
3. 무료 직원 전담 역할, 적재 완료, 두 번째 직원의 가공품 전담을 확인한다. 가격 0은 현 UpgradeService에서 InvalidState이므로 무료 지급을 일반 유료 구매에 그대로 넣을 수 없다.
4. 신규 게임에서 첫 납품·첫 직원·첫 업그레이드·두 번째 직원·두 번째 라인 완료 시간을 기록한다. 3회 이상 측정하고 원재료 만재 정지 시간, 직원 평균 적재량, 트럭 정산 간격도 기록한다.
5. 첫 직원 2~4분, 추천 경로 첫 직원 이후 두 번째 직원 약 5~8분을 목표로 비교한다. 이후 목표는 실측 처리량 기준으로 재가격 책정한다. 새 레벨 전체 구매 시간이나 세 번째 라인 수익을 확정값으로 취급하지 않는다.
